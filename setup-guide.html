Admin Dashboard Setup Guide

Complete setup instructions for your standalone Lyfe Shift admin dashboard

Overview

This standalone admin dashboard is completely separate from your main fitness website but connects to it to gather participant and winner information. It provides a dedicated interface for managing competitions, tracking submissions, and handling prize fulfillment.

User Management

View and manage all competition participants

Winner Tracking

Track winner submissions and proof verification

Shipping Management

Generate labels and track order fulfillment

Analytics & Reports

Export data and generate comprehensive reports

File Structure

Your standalone admin dashboard contains the following files:

standalone-admin-dashboard/ ├── index.html # Main admin dashboard interface ├── admin-dashboard.js # Core dashboard functionality ├── data-connector.js # Connection to main website ├── setup-guide.html # This setup guide └── README.md # Documentation and instructions

Quick Start

1 Deploy the Admin Dashboard

Upload all files to a separate domain or subdomain (e.g., admin.yoursite.com or yoursite.com/admin)

Tip: Keep this completely separate from your main fitness website for security and organization.
2 Access the Dashboard

Navigate to your admin dashboard URL and open index.html

Open Admin Dashboard
3 Test the Connection

Click the "Test Connection" button to verify data sync with your main website

Note: The dashboard will automatically detect and sync data from your main fitness website.
4 Start Managing

Begin using the dashboard to manage participants, track winners, and handle shipping

Data Connection

The admin dashboard connects to your main fitness website to gather information:

Automatic Data Sync

  • User Registration Data - All competition participants
  • Winner Submissions - Proof and shipping information
  • Order Status - Shipping and fulfillment tracking
  • Real-time Updates - Automatic sync every 5 minutes

Data Security

Secure Connection: All data is synchronized securely and stored locally in the admin dashboard. No sensitive information is transmitted over unsecured connections.

Configuration Options

Connection Settings

You can configure the dashboard connection in several ways:

Automatic Detection (Recommended)

The dashboard automatically detects and connects to your main website data. No configuration needed.

Manual Configuration

If needed, you can manually configure the connection by editing the data-connector.js file:

// Set your main website URL dataConnector.setWebsiteUrl('https://your-main-website.com'); // Configure sync settings dataConnector.configureConnection({ websiteUrl: 'https://your-main-website.com', autoSyncInterval: 5, // minutes enableAutoSync: true });

Data Management

Available Data

The admin dashboard provides access to:

  • Participant Information - Names, emails, usernames, registration dates
  • Winner Details - Competition rankings, proof submissions, verification status
  • Shipping Addresses - Complete address information for prize delivery
  • Order Tracking - Status updates, tracking numbers, delivery confirmation
  • Prize Information - Assigned prizes based on competition ranking

Export Capabilities

Export data in multiple formats:

  • CSV Files - For spreadsheet applications
  • Shipping Labels - Ready for fulfillment services
  • Complete Data Backup - JSON format for archival

Security & Access

Important: This admin dashboard contains sensitive participant information. Ensure it's properly secured and only accessible to authorized personnel.

Security Recommendations

  • Deploy on a secure subdomain with HTTPS
  • Implement password protection at the server level
  • Restrict access to specific IP addresses if possible
  • Regularly backup exported data
  • Monitor access logs for unauthorized attempts

Troubleshooting

Common Issues

Connection Issues

If the dashboard shows "Connection Issue":

  • Check that your main website is accessible
  • Verify that participant data exists
  • Click "Test Connection" to retry
No Data Showing

If no participants or winners appear:

  • Ensure users have registered on your main website
  • Check that winners have been marked in the system
  • Use the "Refresh Data" button to force sync
Export Problems

If CSV exports are empty or incomplete:

  • Verify data is showing in the dashboard first
  • Check browser download settings
  • Try refreshing data before exporting
